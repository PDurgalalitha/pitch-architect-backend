# Pitch Architect — FastAPI Backend

An AI-powered backend service for DevPulse AI / Pitch Architect built with **FastAPI**, **Google Vertex AI**, and **Cloud Run**. It handles document ingestion, vector embeddings search, and pitch deck generation logic.

---

## Tech Stack

* **Framework:** Python 3.11 / FastAPI
* **Cloud Infrastructure:** Google Cloud Run, Google Cloud Storage (GCS)
* **AI & Search:** Vertex AI, Vector Search, Gemini 2.5
* **Server:** Uvicorn
